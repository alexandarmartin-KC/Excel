# Output Folder

Denne mappe indeholder genererede filer fra test-scripts.

## Filer

- `CameraStatus.csv` - Opdateres hver gang du kører `/scripts/Run-Test.cmd`

## Bemærk

Filerne i denne mappe oprettes automatisk og bør **ikke** committes til Git (se `.gitignore`).

Excel importerer data fra CSV-filen via en Data Connection som kan refreshes manuelt.
